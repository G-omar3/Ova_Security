# Security policy

This repository is public and intentionally limited to architecture documentation.

## Do not publish

Do not commit:

- credentials, tokens, API keys, SSH keys, private certificates, or passwords;
- production IP addresses, VPN details, private hostnames, or access URLs;
- firewall rule exports, detection rules, or internal configuration files;
- private logs, packet captures, reports, screenshots, or customer data;
- exploit commands or attack playbooks.

## Reporting concerns

If you find sensitive information in this repository, open a private security report through the hosting platform or contact the repository owner through the platform profile.

Do not publish sensitive findings in public issues.
